## 🤔 我能做什么？

### 主页

打卡、看公告、随机 Wiki、看最新帖子。

### Wiki

| 你想做的事 | 难度 | 在哪里做 |
|-----------|------|---------|
| 修改正文错别字 / 补充内容 | ⭐ | 点页面上的小铅笔 |
| 创建新页面（如某位同学的个人页） | ⭐ | 戳左边栏的 '+' |
| 上传图片 | ⭐ | 戳图床标签 |
| 批量修改 / 添加大量内容 | ⭐ | 直接操作 |

如果你之前看过这个 'readme.md' 会发现这里面有难度三颗星的项，社区维护者也让直接网页编辑成为可能！

### 讨论

可以发帖，记录一些碎碎念什么的，或全民公投。

### 文章

发高质文章或脚本。

同一作者发布的文章，如果标题开头前两个字相同，会自动归入集锦，集锦名称取这些文章的最长公共前缀并去掉末尾符号。名称按空格分段时，首段之后的内容只保留完整出现在全部文章标题中的段，避免名称末尾只剩“第”；像“第2季”这样的完整段会保留。“关于”暂不作为集锦。文章广场显示集锦的最新文章，点进集锦可以浏览全部文章；搜索结果会同时展示匹配的文章和集锦。

### 私信

给某个人发私信。

### 通知

你会在这里收到别人的点赞、点踩、评论、投分等等。

### 用户

有用户主页、积分明细、积分商城、名称装扮、用户设置。

### 许愿

花费积分或 RMB 请社区维护者写新功能！

### 协议

一些重要的文档。

## 🔖 Frontmatter 规则

每个 `.md` 文件顶部都有一个 `---` 包围的区域，叫 frontmatter：

```markdown
---
title: 页面标题          # 必填。显示在导航栏和浏览器标签上
icon: fas fa-file-alt    # 可选。Font Awesome 图标类名
---

正文内容...
```

**图标参考（以下都可以用）：**

| 用途 | 图标类名 |
|------|---------|
| 首页 | `fas fa-home` |
| 人物 | `fas fa-user` |
| 校园 | `fas fa-school` |
| 日常 | `fas fa-calendar-day` |
| 通告 | `fas fa-bullhorn` |
| 通用 | `fas fa-file-alt` |
| 图片 | `fas fa-image` |
| 链接 | `fas fa-link` |

> 更多图标见 [Font Awesome 免费图标列表](https://fontawesome.com/search?m=free)

## ⚠️ 注意事项

1. **Pull Request 审核制**：所有修改都需要通过 Pull Request 合并，不要直接推 `main`
2. **文件名规范**：用英文小写 + 短横线（如 `computer-lab.md`），不要用中文文件名
3. **路径区分大小写**：GitHub 和 Linux 区分大小写，`Campus` 和 `campus` 不同
4. **内部链接**：链接本站页面用 `/分类/页面名`（如 `/people/chen-wenyi`），不加 `.md`
5. **敏感内容**：这里的内容对全校公开，注意保护隐私
6. **构建验证**：PR 合并前 GitHub Actions 会自动检查能不能编译通过，黄灯 ❌ 表示有错误不能合并

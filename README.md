这是一个静态部署于 GitHub Pages 的超有梗、超有活力（？）的社区！

这个社区从 Wiki 发展而来，由社区成员共同维护页面与功能，欢迎大家参与。

**在线访问：** https://zack1219happy.github.io/shsfdy2sq/

喜欢的话点一个 star 吧（就是右上角那颗星星）！

---

## 🤔 我能做什么？

如果你不会 markdown 语法，登录后看这里 [shsfdy2sq - Markdown 帮助](https://zack1219happy.github.io/shsfdy2sq/agreement/markdown-helper)。

### 主页

查看公告、打卡并抽取每日运势、浏览最新帖子和随机 Wiki 页面。

### Wiki

| 你想做的事 | 难度 | 在哪里做 |
|-----------|------|---------|
| 修改正文错别字 / 补充内容 | ⭐ | 登录后点 Wiki 页面上的小铅笔，提交后等待审核 |
| 创建新页面（如个人页） | ⭐ | 点左边栏的 '+'，提交后等待审核 |
| 上传图片 | ⭐ | 戳图床标签 |

页面编辑和新建请求都需要审核，通过后才会展示。

### 讨论

可以在论坛发帖、回复帖子，也可以投赞同票或反对票。

与站务有关的疑问也可以发在这里。

### 文章

发高质文章、学习笔记；或写一个 Javascript sandbox——这意味着你可以制作或游玩一些小游戏！

文章广场支持按分类和关键词搜索文章与集锦。系统会按作者和标题规则自动生成集锦；打开集锦可以浏览其中的文章。

### 私信

给某个人发私信。

当然他不一定收得到就是了……

### 通知

这里会显示点赞、点踩、回复、私信、提及和投分等提醒。

### 用户

有用户主页、积分明细、积分商城、名称装扮、表情库管理和用户设置。

你可以通过每日的小人物攒积分——当然发文章和许愿也不错！～然后购买你想要的名字装扮。

还可以自己维护表情包体系，争取让别人都来用！

### 许愿

提交功能愿望，并按页面规则使用积分或 RMB 支持。

你也可以参与到社区的构建中咯~使用自然语言进行 NegroCoding，目前由 Irade-tqy 驱动（bushi）。
